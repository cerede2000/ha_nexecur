# Politique de sécurité

Ne publiez jamais dans une issue votre code de raccordement, votre PIN, un
jeton de session, une adresse ou le nom complet d’un site.

Pour signaler une vulnérabilité, utilisez le signalement privé de vulnérabilité
GitHub du dépôt lorsqu’il est disponible. À défaut, ouvrez une issue sans
inclure le secret concerné et demandez un canal de communication privé.

Les versions de sécurité sont publiées dans les releases GitHub. Il est
recommandé d’utiliser la dernière version disponible.
